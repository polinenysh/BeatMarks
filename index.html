Импорт и экспорт JSON

JSON нужен, чтобы перенести список меток на другое устройство или сделать резервную копию.

Выбери MP3-файл и импортируй массив меток. Он заменит метки выбранного трека.

[
  {
    "label": "Вступление",
    "time": 0
  },
  {
    "label": "Припев",
    "time": 72.5
  }
]

label — название метки. time — время в секундах от начала трека, можно с дробной частью. Сохрани массив в файл с расширением .json.

Файл из «Экспорт JSON» тоже поддерживается. При его импорте заменяются метки всех треков.
